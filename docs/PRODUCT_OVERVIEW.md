# Product Overview

## Product Name

ATLAS

Aggregated Tunisian Learning & Academic System

## Product Purpose

ATLAS is an academic learning platform designed to support students, teachers,
administrators, and superadministrators in a shared higher-education ecosystem.

Its purpose is to:

- aggregate course content
- support AI-assisted study workflows
- enable contribution and moderation pipelines
- provide gamified learning motivation
- centralize educational administration in a multi-role platform

## Primary User Roles

### Student

Students can:

- browse and access courses
- read course materials
- use AI chat, flashcards, quizzes, summaries, and mind maps
- view notifications
- contribute learning materials
- track history and gamification data

### Teacher

Teachers can:

- review contributions
- access teacher analytics
- manage courses and uploads
- monitor educational activity in their scope

### Admin

Admins can:

- manage users
- review platform reports
- moderate contributions
- review dashboard-level operational metrics

### Superadmin

Superadmins can:

- view cross-establishment information
- manage multi-establishment visibility
- oversee platform-wide institutional structure

## Core Product Modules

### Authentication and Identity

- registration
- login
- OTP verification
- password reset
- role-aware access control

### Course Management

- browse courses
- view course detail
- access versions and downloads
- upload and manage course-related materials

### Study Tools

- reader
- AI chat (RAG)
- flashcards
- quizzes
- summaries
- mind maps

### Contributions and Moderation

- student content contribution
- teacher/admin review queue
- reporting and moderation review

### Gamification

- XP
- leaderboard
- public profile
- badge and progress-related surfaces

### Dashboards

- student dashboard
- teacher dashboard
- admin dashboard
- superadmin overview surfaces

## Product Strengths

- role-based learning platform architecture
- AI-assisted learning workflows already integrated into the core product
- multilingual design intent including Arabic support
- centralized API and typed frontend data layer
- modern frontend stack and scalable backend stack

## Current Product Limitations

- some analytics surfaces remain light
- some workflows are still operationally minimal rather than feature-rich
- some UX paths need more depth after content generation
- administrative action surfaces are not yet fully complete

## Ideal Product Positioning

ATLAS is best positioned as:

- an AI-enhanced academic platform for structured learning
- a unified education workspace for Tunisian higher education
- a contribution-driven content and study ecosystem
