# ATLAS Documentation

This folder contains product, technical, process, and operational documentation
for the ATLAS application.

## Document Index

- `ASSESSMENT.md`
  Current product assessment, readiness status, missing capabilities, and theme review.
- `PRODUCT_OVERVIEW.md`
  Product-level description of what ATLAS is, who it serves, and its core modules.
- `USER_GUIDE.md`
  End-user guidance for students, teachers, admins, and superadmins.
- `API_REFERENCE.md`
  High-level API documentation for frontend/backend integration.
- `ARCHITECTURE.md`
  System architecture, major layers, data flow, and deployment shape.
- `REQUIREMENTS.md`
  Functional and non-functional requirements summary.
- `DEVELOPMENT_PROCESS.md`
  Development workflow, coding process, QA gates, and release approach.
- `TEST_REPORT.md`
  Current testing posture, validation already performed, and testing gaps.
- `DEPLOYMENT_AND_OPERATIONS.md`
  Environment setup, runtime dependencies, and operational guidance.
- `MAINTENANCE.md`
  Maintenance, repair, support, and ongoing cleanup guidance.
- `RELEASE_READINESS.md`
  Release decision summary and go-live checklist.

## Recommended Reading Order

1. `ASSESSMENT.md`
2. `PRODUCT_OVERVIEW.md`
3. `ARCHITECTURE.md`
4. `API_REFERENCE.md`
5. `RELEASE_READINESS.md`

## Notes

- This documentation reflects the current harmonized state of the codebase after
  the frontend/backend coherence pass.
- Some items are intentionally marked as follow-up work where the product is
  functional but not yet fully production-complete.
